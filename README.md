# Polygroups of order 5 — enumeration and classification

Complete dataset and code for the exhaustive enumeration of the **4,412 pairwise non-isomorphic polygroups of order 5**, accompanying the paper

> P. Asadzadeh, M. Farshi, B. Davvaz, *An Enumeration and Classification of Non-isomorphic Polygroups of Order 5: A Structural Analysis via Algebraic and Logical Generators*, Discussiones Mathematicae – General Algebra and Applications (revised version).

## Result

| order | 2 | 3 | 4 | 5 |
|---|---|---|---|---|
| non-isomorphic polygroups | 2 | 10 | 102 | **4,412** |

Of the 4,412 polygroups of order 5, 1,019 are non-primitive (have a proper subpolygroup) and 3,393 are primitive. The inverse map `x -> x^-1` of a polygroup is an involution, so for order 5 only three inverse types occur (1+1+1+1: 3,013 polygroups; 2+1+1: 1,316; 2+2: 83).

## Repository layout

| path | content |
|---|---|
| `src/polygroups_n5.cpp` | main two-phase search (C++17, OpenMP): constructive extension of the polygroups of order 2, 3, 4 + exhaustive backtracking per inverse type, canonical-form isomorphism rejection, final self-check |
| `src/enum_indep.cpp` | independent verifier: enumerates unions of orbits of the reversibility relation (no backtracking), orders 2–5 in about one second |
| `data/polygroups_order5.csv` | the 4,412 canonical multiplication tables, sorted by key |
| `data/polygroups_order5_invariants.csv` | one row per polygroup: key, inverse type, primitive, commutative, fundamental group, `d(P)`, `g(P)`, `|Aut(P)|`, `lambda(P)` |
| `results/run_log.txt` | log of the run reported in the paper |
| `notebooks/verification.ipynb` | Jupyter / Google Colab notebook reproducing every number and table of the paper |

## Data format

`polygroups_order5.csv` consists of blocks

```
Unique Structure #k,Key: <integer>
"{1}","{2}","{3}","{4}","{5}"
...                           (5 rows; row x, column y contains the set x o y)
```

Elements are `1..5`, `1` is the identity. `Key` is the canonical key: the 128-bit integer obtained by packing the 16 cells `T[i][j]`, `2<=i,j<=5`, row by row (5 bits per cell, as a subset bitmask, first cell least significant), minimised over all 24 renamings of the elements `2..5`. Two tables are isomorphic iff their keys are equal.

## Reproducing the results

**Google Colab (recommended).** Open `notebooks/verification.ipynb`, choose *Runtime → Run all*. It clones this repository, compiles the C++ verifier, and checks that (i) all 4,412 tables are polygroups and pairwise non-isomorphic, (ii) the independent enumeration gives the same 4,412 classes (and 2, 10, 102 for orders 2, 3, 4), (iii) the orbit–stabiliser identity gives 86,716 normalised tables, and (iv) all tables of the paper (inverse types, primitive/non-primitive, fundamental groups, algebraic generation `d(P)`, `g(P)`, logical generation `lambda(P)`) are reproduced. Set `RUN_MAIN_SEARCH = True` in the last step to also rerun the main search.

**Command line.**

```bash
g++ -O2 -std=c++17 -o enum_indep src/enum_indep.cpp
./enum_indep 5 > out5.txt                       # independent enumeration (labelled tables)

g++ -O2 -std=c++17 -fopenmp -o polygroups_n5 src/polygroups_n5.cpp
./polygroups_n5                                 # main search; writes polygroups_final_results.csv
```

The main search takes roughly 15 minutes on two cores (all candidates are re-verified at the end: "Self-check: 4412 tables verified, 0 failed").

## Notes on the revision

* The inverse map is an involution (Lemma 1 of the paper); the earlier inverse cases `3+1` and `4` were removed.
* The order-4 database used for pruning is generated by the program, not typed by hand.
* The split into 1,019 non-primitive / 3,393 primitive polygroups replaces the earlier (incorrect) 566 / 3,846.
